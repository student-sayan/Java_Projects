## Getting Started

### Prerequisites

Make sure Java Development Kit (JDK) is installed on your system.

Check your Java installation:

```bash
java --version
```

Check the Java compiler:

```bash
javac --version
```

### Clone the Repository

```bash
git clone https://github.com/student-sayan/Java_Projects.git
```

Navigate to the project directory:

```bash
cd Java_Projects
```

### Compile and Run

For example, to run the Armstrong Number program:

```bash
javac Armstrong_Number.java
java Armstrong_Number
```

You can replace `Armstrong_Number` with the name of any Java class in the repository.
